# ASB 이벤트 발화 구간 — r8 원본 검증

## 1. 기능 개요와 화면 연결

플레이어 애니메이션의 Event 부착 노드와 재질 이벤트는 직전·현재 프레임 사이의 키를 조회해 이벤트 큐에 넣는다. 점 키는 `직전 < 키 ≤ 현재`다 [실행]. 이 문서는 발화 구간만 확정하며 이벤트별 효과·소리의 전체 연결을 확정하지 않는다.

## 2. 분석 대상과 자료

Splatoon 3 v0 main. 원본 C: `analysis/decomp/r8_graphics/gp_core.c`(0x71039c7910/39c73e4), `bake_event.c`(08a4668/39c7e20), `paint_loader_event.c`(08a4790). 종전 Event 진입은 `analysis/decomp/render/r4_asnode2.c`의 0x71039c6d98이다.

## 3. 진입점과 호출 흐름 [판독]

Event 노드 0x71039c6d98 → 이벤트명에 대응하는 BAEV 리소스 → 0x71039c7910 → 그룹 조회 0x71008a4668 → 채널별 키 조회 0x71008a4790 → 0x71039c7e20 → 점 이벤트 39a8f58 / 구간 이벤트 39a91a8. 재질 이벤트 진입 39c73e4도 같은 조회기를 쓰며 재질용 프레임 접기 모드가 1이다.

## 4. 구조체·필드 [판독]

| 객체 | 필드 | 의미 |

| 조회 Q 24B | +0/+4 f32 | from/to |

| Q | +10..+16 byte | -1 키 허용, -2 키 허용, 점 활성, 구간 활성, to에서 활성인 구간, 종료 통과, 전체 강제 |

## 5. 상태 전이 [판독]

39c7910은 엔트리 +4 현재, +8 직전, +14 스켈레탈 끝을 읽는다. 재질 모드는 +30 끝을 쓰며 반복 플래그 0x100이면 끝에 대해 프레임을 접고, 아니면 끝으로 제한한다. 처음 조회일 때 엔트리 +1C가 0 이상이면 그 값을 시작으로 사용할 수 있다.

직전이 현재보다 큰 경우 `현재+(끝-직전) < 직전-현재`이면 반복 경계를 넘었다고 분류한다. `[직전, 끝]`을 조회한 뒤 `[-1, 현재]`를 조회한다. 반대이면 직전을 `직전-끝`으로 옮겨 한 번 조회한다. 결과를 전달할 때 최대 64개로 제한한다. 이 분기를 임의의 역재생 해석으로 바꾸면 안 된다.

## 6. 판정식 [실행]+[판독]

```text
point = enablePoint && (forceAll || (key == -2 && allowMinus2)
          || (key == -1 && allowMinus1) || from < key && key <= to)
inside = allowActive && start <= to && (end < 0 || to <= end)
ended = end >= 0 && !forceAll && allowEnd && start > from && end <= to
range = enableRange && (forceAll || inside || ended)
```

ID 필터가 0 이상이면 채널 ID가 같은 것만 조회한다. 구간 끝은 `to == end`에서도 활성 조건에 들어간다. ended에는 **start > from** 조건이 들어간다. 조회기는 출력 용량까지만 기록하면서 반환 개수에는 용량 이후의 일치도 포함한다 [판독]. 호출자가 다시 64개로 제한한다.

## 7. 애니메이션·이펙트·소리 연결

39c7e20은 점·구간 종류에 따라 다른 큐 삽입기를 부르고 애니메이션·전환 가중을 이벤트에 전달한다 [판독]. 개별 BAEV 이벤트가 어떤 XLINK action에 연결되는지와 GPU 포즈 결과는 이 검증에 포함되지 않는다.

## 8. 다른 기능과의 상호작용

스켈레탈·재질 이벤트가 조회기를 공유한다. 부착 수집 39bcb9c는 이벤트 시간 계산이나 FloatBlend 동기화 함수가 아니다(기존 r6 정정 유지).

## 9. 웹 포팅 구조

권장 모듈 `BaevIntervalQuery`는 위 24B 조회와 채널 목록을 입력으로 받는다. 실제 프레임 전진 뒤에 엔트리의 직전/현재/끝으로 조회하며, 반복 경계는 두 구간으로 나누는 원본 순서와 64개 제한을 유지한다. 효과·소리 action 연결은 별도 데이터 해석이 필요하다.

## 10. 실행 검증

`web/tools/r8_gfx_paint_event_emu.py`: 원본 08a4790 전체를 Unicorn에서 실행. 점 **2048/2048**, 구간 **2048/2048** 독립 판정과 일치. 합성 채널·키·7개 플래그·ID 필터, 음수 특수 키 및 시작/끝 동일 경계를 포함한다. 함수 스텁 없음. 결과 `analysis/completion/r8/graphics_paint_event_emu.json`. 39c7910의 엔진 콜백·원본 BAEV 파일 전체 연결은 실행하지 않았으므로 반복 경계 구성은 [판독]이다.

## 11. 미확정과 다음 근거

BAEV 파일의 모든 섹션·리로케이션, 다층 포즈 샘플러 합성은 [미확정]. 다음은 BAEV 런타임 로더와 39bc994/39c9ac4, SDK 포즈 합성 호출이다. 2026-10-03 r8: 기존 Event의 '발화 구간 미확정'은 위 원본 조회기로 정정했다. InitialFrame 방식 3은 이후 [별도 검증](asb_initial_frame.md)으로 해소했다. BAEV 파일 전체 섹션은 여전히 미확정이다.
