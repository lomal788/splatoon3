# ASB 실수 파라미터 — 변화율과 각도

## 1. 기능 개요

ASB 실수 파라미터는 블랙보드 값을 캐시에 저장하고 변화율 제한을 거친 뒤 scale/offset/min/max를 적용한다. 원본 변화율 0은 제한 없이 새 값을 쓴다. 모드 1은 도 단위 각도, 모드 2는 라디안 각도다 [실행]+[판독].

## 2. 원본 자료

`analysis/decomp/render/r4_asnode2.c` 3997de0(기존 값 참조 판독), 새 `analysis/decomp/r8_graphics/asb_angle_rate.c` 3997c10, 원본 AArch64 명령. SHARED/FUNCS/decomp_index를 먼저 대조해 기존 참조 태그 판독은 재계상하지 않았다.

## 3. 호출 흐름 [판독]

3997de0 → 실수 파라미터표/블랙보드 값 → 인스턴스 캐시 탐색 → rate>0일 때 제한 → scale/offset/clamp. 모드 1/2의 제한은 3997c10이다. 테이블 항목 0x20B 구조와 값 출처는 anim_state_machine §2.8의 기존 근거다.

## 4. 주요 구조 [판독]

테이블 = {내부 값 참조 0, rate 4, mode 8(u32), initial C, scale10, offset14, min18, max1C}. 캐시 값이 +∞이면 initial>=0일 때 initial, 그 밖에는 새 블랙보드 값으로 초기화한다. 인스턴스 캐시가 없으면 제한을 적용하지 않는다.

## 5. 수명·갱신 [판독]

rate가 양수일 때만 이전 캐시에서 새 값으로 접근한다. rate<=0이면 새 값을 즉시 저장한다. dt=0이고 양수 rate이면 기존 값이 유지된다(각도는 원본 감기/단위 변환의 f32 오차가 남을 수 있다). 최종 clamp는 캐시를 잘라 저장하는 연산이 아니며 scale/offset 후 반환값에 적용한다.

## 6. 원본 식 [판독]+[실행]

일반 모드: step=f32(rate*dt). 새 값>현재면 min(새 값,f32(현재+step)), 새 값<현재면 max(새 값,f32(현재-step))이다. 원본에는 반대 방향으로 넘어간 계산을 새 값으로 되돌리는 비교도 있다.

각도 감기 W(x): q=f32(x*0x3e22f983), n=floor(q), v=f32(x-f32(f32(n)*0x40c90fdb)); 0<v<2π이면 v, 그 밖은 +0. 원본 floor는 fcvtzs 뒤 음수 비정수면 1을 빼는 식이다. 현재와 목표를 W로 감는다. 차이가 |d|<=2^-23이면 목표를 바로 저장한다. d>π이면 현재에 2π, d<-π이면 목표에 2π를 더해 짧은 방향으로 접근한다. 결과를 다시 감고 오차가 2^-23 이내면 목표로 맞춘다. 정확히 π인 차이는 +2π 보정을 하지 않는다.

모드1은 현재·목표·rate에 0x3c8efa35(0.017453292)를 곱해 3997c10에 넘긴 뒤 0x42652ee0(57.295776)를 곱한다. 모드2는 라디안 그대로 넘긴다. 출력=f32(offset+f32(scale*cache)), 이어 min/max 비교. 계산 중간은 f32이며 FMA로 합치지 않는다.

## 7. 데이터 연결

사람 ASB StringerTiltDeg의 모드1/90 상수는 기존 데이터다. 이번 실행은 사격장에서 쓰는 실수 값 공급과 공통 제한기의 정확한 동작을 다뤘다. 다른 무기의 실제 작동은 분석하지 않았다.

## 8. 상호작용

FloatBlend 자식 동기화는 asb_node_runtime.md의 별도 경로다. 이번 캐시 실행을 ASB 전체 포즈·클립 선택 실행으로 확대하지 않는다.

## 9. 웹 반영 필요

impl/render.md §3의 rate0 추정을 해소: rate0은 즉시 갱신. 양수 rate 일반 접근, 모드1 도→라디안→도 및 모드2 라디안 감기를 보존한다. 구현 파일은 수정하지 않았다.

## 10. 검증

`web/tools/r8_gfx_angle_rate_emu.py` → `analysis/completion/r8/graphics_angle_rate_emu.json`: 3997c10 2048/2048 반환 저장비트 일치(스텁 없음), 3997de0 1536/1536 출력·캐시 비트 일치. mode0/1/2, rate0/음수/양수, 초기 +∞, min/max 후처리를 포함했다. 후자의 유일 스텁은 블랙보드 테이블 식별자 vt+18=0 반환이다. 실제 값은 원본 builtin0(ctx+1DC)에서 읽고 원본 캐시 탐색을 실행했다. 유한 입력만 검증했으며 전체 ASB 인스턴스는 실행하지 않았다.

## 11. 정정·미확정
