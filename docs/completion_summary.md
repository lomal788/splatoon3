## 2. 이번에 확정·정정한 핵심

- **[실행]+[판독] 이동:** 능력 104의 오징어 목표 속도 배율은 0.9다. SM+0xd4의 변위 투영, 외부 이동 보정, 명령량 상한을 확정했다. 롤·벽점프 횟수 n은 s32이며 감쇠 계산 후 증가한다. 입력 경로의 형태 이탈 및 90프레임을 초과한 리셋 조건은 판독했다. B+820은 이동 이력 버퍼다. [이동 보완 §6](player/solo_completion.md).
- **[실행]+[판독]+[데이터] 카메라:** +68은 +3c부터의 X/Y/Z 기저 포인터다. X=normalize(up×Z), Z=normalize(pos−at)이며 수직 특이 시선에서 이전 기저를 유지한다. 붐 질의 형상은 hknpSphereShape이고 반경 하한은 0.3이다. 실제 런타임 설정값은 미확정이다. [카메라 보완 §3~§6](camera/solo_completion.md).
- **[판독]+[실행] 탄:** 생성 판정 16e3af4는 원격 탄의 거리·시야 컬링이다. 로컬 탄의 짧은 허용 경로를 실행 확인했다. 다른 생성 실패나 예산 경로의 존재 여부는 별도 미확정이다. 기존 잉크 소모·회복, 첫발 게이트, 총구·분할 인덱스 근거를 원본 문서에 연결했다. [슈터 보완](weapon/solo_shooter.md).
- **[실행]+[판독] 충돌:** Default/Same/Other 선택과 양방향 layer/sublayer 마스크 AND, shapeTag 행 선택 한 단계, 리셋 시 컨트롤러 원점=게임 위치+최종 캡슐 반경×월드 Y를 확인했다. 형상별 override, 로더 연결, 평상시 위치 동기화는 미확정이다. [충돌 보완 §6](physics/collision_runtime_completion.md).
- **[실행]+[판독] 그래픽:** 모자의 Head 행렬×ManualBindSRT 결합과 SIMD FMLA 순서를 확정했다. HairArrange 후보였던 26e613c는 모자 SRT 계산으로 정정했다. MainLight 경로의 오래된 추정은 기존 판독 근거를 재사용해 해소했다. [그래픽 보완](graphics/solo_graphics_audit.md).
- **[판독]+[데이터]/[실행] 효과:** FIXED color0/1·alpha0/1의 키 0 패치, ball VAT A 채널의 법선 복호화와 시간 clamp, 음성 제한기 3종의 비교 키를 확인했다. VAT 표본 재구현은 GPU 원본 실행으로 집계하지 않았다. [효과 보완](effect_sound/solo_fx_audit.md).
